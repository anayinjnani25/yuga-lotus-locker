Yuga Locker Build Manual

Arduino circuit with a sensor for every puzzle stage, how to build and wire each part, a manual override, and a spring-powered version with no electronics at all.

What each stage senses

Every puzzle has a physical lock and a sensor. The physical part stops the child from skipping ahead; the sensor lets the Arduino see what happened, show the next instruction on the screen and light the lotus.

The Uno does not have enough pins for 8 ring and band sensors plus the keypad, so the eight sensors go through a PCF8574 input module. It shares the two I2C wires (A4, A5) with the screen.

Power rule: never run the two servos and the LED ring from the Uno's own 5 V pin. They draw too much current and the Uno will restart mid-game. Feed them from the 5 V adapter rail and join all the grounds.

Build steps

Build the mechanical parts first and check that each one moves freely before you add any sensor.

Part ABox, lid latch and lid sensor

  1. Make a hollow base about 20 × 20 cm and 6 cm deep with a removable bottom plate. This is the electronics bay.
  2. Hinge the four walls to the base with fabric tape so they fold down, and hinge the lid to the back wall.
  3. Fit the latch. Bend a paper-clip loop under the front edge of the lid. Mount the lid servo inside the top of the front wall so its horn hooks the loop at 0° and swings clear at 90°.
  4. Add the lid sensor. Glue a magnet under the lid's front edge and a reed switch in the top of the front wall directly below it.
  5. Cut windows in the front of the base for the keypad and the screen. Run the wall wires down through the hinge gap with a loose loop so the wall can fold.

Part BPicture puzzle bands

  1. Fix the core tube (50 mm PVC pipe or a strong card tube) upright in the centre of the base.
  2. Make three card rings slightly wider than the tube so they turn freely. Stack them with thin spacers between.
  3. Cut each yuga picture into three horizontal strips. Glue the top strips of all four pictures around band 1, the middle strips around band 2 and the bottom strips around band 3, in the same order.
  4. Hide a magnet inside each band behind the Satya strip. Tape a reed switch inside the tube at each band's height, at the front mark. When a band is turned to the correct spot, its switch closes.
  5. Cut four notches in the lower edge of band 3. Only when the puzzle is solved do the notches sit over the four leaf sockets. Otherwise the band covers them and no leaf fits.

Part CLeaf ring, sockets and leaves

  1. Make the leaf ring below the bands. Add a stopper peg so it can turn only about a quarter turn. That keeps its wires from twisting.
  2. Cut four shaped sockets (circle, triangle, square, star), one per yuga, and glue a reed switch behind each.
  3. Make the leaves from card covered in copper tape. Give each a peg of its yuga's shape with a magnet in the tip, so it only fits and only triggers its own socket.
  4. Line up the holes. Drill a 10 mm hole in the ring and one in the core at the same height. Glue a magnet on the ring beside its hole and a reed switch on the core so it closes only when the holes line up.
  5. Route the ring wires as one bundle through a slot into the tube and down to the bay, leaving a loose loop.

Part DPush rod, lotus and button

  1. Fit the push rod (5 mm dowel or skewer) up the centre of the tube through two card guide discs.
  2. Mount the lotus servo in the bay under the tube so its horn lifts the rod's foot about 2–3 cm. Do not glue the rod to the horn; it just rests on it (this matters for the manual override).
  3. Build the umbrella: a collar on top of the rod, four ice-cream-stick struts from the collar to the petals, petals hinged at the rim with tape. Add a pen spring under the collar to help the petals close.
  4. Place the NeoPixel ring on the top disc under the lotus, facing up, with its wires down the tube.
  5. Fit the microswitch inside the tube opposite the button hole, so the button presses its lever only when pushed all the way in.
  6. Coin holders: a small pocket on each petal, or a magnet if your coins stick to one.

Part EElectronics bay

  1. Mount the Uno, PCF8574 and breadboard on the bottom plate with double-sided foam tape.
  2. Make the power rail on the breadboard: adapter +5 V and GND in, capacitor across the rail (long leg to +5 V).
  3. Wire in this order, testing after each: LCD and PCF8574 on I2C, keypad, reed switches, microswitch, servos, LED ring, buzzer. Follow the diagram above.
  4. Label every wire with masking tape (for example "P2 Dwapara"). It saves a lot of time when something needs fixing.

Test and calibrate

  1. Install the libraries in Arduino IDE (Tools → Manage Libraries): Keypad, LiquidCrystal I2C, Adafruit NeoPixel. Upload yuga_lotus_locker_v2.ino.
  2. Enter test mode: type 0000. The screen shows every sensor live, for example Lf1000 Bd110 R0. A 1 means that magnet or button is detected.
  3. Check each sensor by moving its magnet or pressing it and watching its digit change. Move reed switches closer if a digit does not change.
  4. Test the motors: in test mode, 1 opens the latch, 2 opens the lotus, 3 closes both and 4 lights the LEDs. If a movement is too small or too big, change LID_OPEN or LOTUS_OPEN at the top of the code and upload again.
  5. Press * to leave test mode and play through the whole game once.

Manual override (no power needed)

All the puzzles are physical, so they keep working without electricity. Only the lid latch and the lotus need power, and each has a hidden manual release.

Lid: hidden latch release

Drill a 3 mm pin hole in the back wall where it lines up with the servo horn, and hide it behind a small carved slide. Push a straightened paper clip in to nudge the horn off the loop. An unpowered servo can be turned by hand.

Lotus: push from below

The rod only rests on the servo horn, so it can be lifted without the motor. Leave a finger hole in the bay's bottom plate under the rod, or use a longer button with a ramp tip that lifts the rod by itself when pushed in.

Teacher code

With power on, code 0000 opens test mode, where key 1 opens the latch and 2 opens the lotus without solving anything. Change TEST_CODE in the program before the children play.

Mechanical version with springs (no electronics)

This version needs no Arduino, no batteries and no wires. Springs do all the work: the lid pops up when the code is right, the walls spring open, the bands and ring click into place, and the lotus bursts open when the button trips a catch, like a jack-in-the-box.

Stage 1: combination dial lock

  1. Number wheel. Digits 0–9 around the rim and one notch, cut where the rim faces the bolt when the correct digit is in the window.
  2. Bolt tooth rests on the rim. It can only slide in when all four notches face it.
  3. Bolt spring (rubber band or small tension spring) pulls the bolt toward the wheels.
  1. Guides (straw pieces) keep the bolt sliding straight.
  2. Lid hook. A bent paper clip hangs from the lid. The bolt's end sits in its eye, so the lid stays shut.
  3. Lid pop-up spring (from a ball pen) in a pocket on top of the wall. It lifts the lid as soon as the bolt lets go.

BuildDial lock

  1. Cut four wheels 6 cm across from three layers of card glued together (or foam board), each with a centre hole for a 5 mm dowel axle.
  2. Mark 0–9 evenly round each rim (every 36°). Mount the axle inside the front wall so one row of digits shows through a slot window.
  3. Cut the notches. Turn wheel 1 to show 1, wheel 2 to 7, wheel 3 to 0 and wheel 4 to 9. Mark the point on each rim that faces the bolt, then cut an 8 mm notch there.
  4. Make the bolt from an ice-cream stick with four stick-piece teeth, one touching each wheel. Slide it through two straw guides and hook the spring on.
  5. Fit the hook and pop-up spring. Glue a paper-clip hook under the lid so the bolt's end passes through its eye. Put a pen spring in a short straw pocket on top of the wall.
  6. Add a knob (a bead on the bolt, poking out of the side) so you can pull the bolt back when relocking.

To change the code, cut new notches in fresh wheels. A washer between the wheels adds friction so they don't spin on their own.

Stages 2 to 4: walls, click-stops and leaf ring

Walls that spring open

Take the springs out of four wooden clothespins. Tape one leg of each spring to the base and the other leg to the bottom of a wall, next to its hinge. The springs try to fold the walls outward, but a rim under the lid holds their tops in. When the lid pops up, the box opens out like a flower. Glue a small stopper so each wall stops flat.

Click-stops for the bands

Push a pen spring and a bead into a short straw glued inside the tube at each band's height, so the bead presses out through a hole in the tube wall. Poke four shallow dimples inside each band, one per picture position. The band now clicks at every picture, which makes the puzzle feel precise.

Leaf ring and aligned holes

Sink the ring slightly into a smooth sleeve so it can't be gripped: only the leaves can turn it. Give each leaf peg its yuga's shape (circle, triangle, square, star). Add one more bead click-stop with a single dimple, at the point where the ring hole lines up with the tube hole. Add a stopper peg so the ring turns only about a quarter turn.

Stage 5: spring-loaded lotus trigger

  1. Copper petals, taped hinges at the rim, a coin pocket on each.
  2. Collar and struts open the petals like umbrella ribs.
  3. Push rod with a notch near its foot.
  4. Main lotus spring under the foot, squeezed when the lotus is closed.
  5. Catch lever on a toothpick pivot. Its tooth sits in the rod's notch and holds the spring down.
  1. Catch spring keeps the tooth pressed into the notch.
  2. Button (8 mm dowel) through the ring hole and tube hole. Its tip presses the top of the lever.
  3. Button spring pushes the button back out after use.
  4. Leaf ring. Its hole must line up with the tube hole, or the button can't reach the lever.

BuildLotus trigger

  1. Make the rod from a 5 mm dowel. Glue a card disc (the foot) near the bottom and cut a 3 mm notch 2 cm above the foot.
  2. Put the main spring in the bottom of the tube, under the foot. A 30–40 mm compression spring from a spring kit, or the spring from a stapler, works well.
  3. Fit the catch lever, a 5 cm piece of ice-cream stick. Push a toothpick through the tube wall as its pivot. Glue a small tooth on its lower end and add a pen spring behind it.
  4. Line up the button hole. Drill the tube hole at exactly the height of the lever's top end, so the button presses the lever and not the rod.
  5. Limit the stroke. Glue a stop collar on the rod so it can only rise 2–3 cm. Otherwise it can fling the petals off their hinges.
  6. Cock it: close the petals by hand and press down until you hear the click. Test the button several times before you add the coins.

Start with a gentle spring. If the lotus snaps open too hard, cut a coil off the spring or use a weaker one. Keep fingers out of the petals when you press the button.

ResetLocking the mechanical box again

  1. Put the coins back and press the petals closed until the catch clicks.
  2. Turn the ring back with the leaves, then pull the leaves out.
  3. Turn the picture bands to mix up the pictures.
  4. Lift the walls up and hold them. Pull the bolt knob back, close the lid (squeezing its spring), then let the bolt go into the hook's eye.
  5. Spin the number wheels away from 1-7-0-9.

How to play

For the player

  1. Type the secret code on the keypad. The lid unlocks. Open it and fold the walls down.
  2. Turn the three picture bands until all four yuga pictures are whole. The screen shows a Y for each correct band.
  3. Match each leaf to its yuga socket and push it in. The lotus lights up in that yuga's metal colour.
  4. Use the leaves as handles and turn the ring until the screen says the holes line up.
  5. Push the button all the way in. The lotus opens: collect a coin from each petal.
  6. Press * to close the lotus, take the leaves out and close the lid. The box locks itself.

/*
  Yuga Lotus Locker v2 - Arduino Uno, every puzzle stage has a sensor
  ------------------------------------------------------------------
  Stage 1  Code 1709 on the keypad          -> lid latch servo opens
  Stage 2  Picture puzzle: 3 turning bands   -> 3 reed switches (one per band)
  Stage 3  Four yuga leaves in their sockets -> 4 reed switches
  Stage 4  Ring turned until holes line up   -> 1 reed switch
  Stage 5  Button pushed through the holes   -> microswitch -> lotus servo opens petals
  Reset    * closes the lotus. Take the leaves out and close the lid:
           the box locks itself (lid reed switch).
  Test     Type 0000 when locked to see every sensor live on the screen.
           In test mode: 1 = open latch, 2 = open lotus, 3 = close both,
           4 = light test, * = leave test mode.

  Libraries (Arduino IDE > Tools > Manage Libraries):
    Keypad (Mark Stanley), LiquidCrystal I2C (Frank de Brabander),
    Adafruit NeoPixel (Adafruit). Servo and Wire are built in.

  Wiring (Arduino Uno)
    Keypad 3x4           rows D2 D3 D4 D5, cols D6 D7 D8
    Lid latch servo      D9   (power from the 5 V supply)
    Lotus servo          D10  (power from the 5 V supply)
    NeoPixel ring (8)    D11 through a 330 ohm resistor
    Buzzer               D12
    Button microswitch   A0 -> GND
    Lid closed reed      A1 -> GND
    I2C bus              A4 = SDA, A5 = SCL -> LCD (0x27) and PCF8574 (0x20)
    PCF8574 inputs (each switch goes to GND):
      P0 Satya leaf, P1 Treta leaf, P2 Dwapara leaf, P3 Kali leaf,
      P4 band 1 (top), P5 band 2 (middle), P6 band 3 (bottom), P7 ring aligned
*/

#include <Keypad.h>
#include <Servo.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Adafruit_NeoPixel.h>

// ---------- settings you can change ----------
const char SECRET_CODE[] = "1709";
const char TEST_CODE[]   = "0000";
const int LID_LOCKED   = 0;     // latch servo angles
const int LID_OPEN     = 90;
const int LOTUS_CLOSED = 10;    // lotus servo angles: rod should rise 2-3 cm
const int LOTUS_OPEN   = 150;
const byte LCD_ADDR = 0x27;     // try 0x3F if the screen is blank
const byte PCF_ADDR = 0x20;     // PCF8574 with A0 A1 A2 set to GND

// ---------- pins ----------
const byte ROWS = 4, COLS = 3;
char keys[ROWS][COLS] = {{'1','2','3'},{'4','5','6'},{'7','8','9'},{'*','0','#'}};
byte rowPins[ROWS] = {2, 3, 4, 5};
byte colPins[COLS] = {6, 7, 8};
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

const byte PIN_LID_SERVO = 9, PIN_LOTUS_SERVO = 10, PIN_LEDS = 11, PIN_BUZZER = 12;
const byte PIN_BUTTON = A0, PIN_LID_CLOSED = A1;

// PCF8574 bit numbers
const byte BIT_LEAF[4] = {0, 1, 2, 3};
const byte BIT_BAND[3] = {4, 5, 6};
const byte BIT_RING = 7;

// ---------- yuga data ----------
const char* YUGA_NAME[4] = {"Satya Yuga", "Treta Yuga", "Dwapara Yuga", "Kali Yuga"};
const char* YUGA_COIN[4] = {"Gold coin", "Silver coin", "Copper coin", "Iron coin"};
const uint8_t YUGA_RGB[4][3] = {{255,170,0},{190,200,220},{230,100,40},{80,90,110}};

LiquidCrystal_I2C lcd(LCD_ADDR, 16, 2);
Adafruit_NeoPixel leds(8, PIN_LEDS, NEO_GRB + NEO_KHZ800);
Servo lidServo, lotusServo;

enum State { LOCKED, LOCKOUT, PUZZLE, LEAVES, RING, BUTTON, OPEN, RESETTING, TEST };
State state = LOCKED;

char entered[5];
byte codeLen = 0, wrongTries = 0, coinShown = 0;
byte lastInputs = 0xFF;
bool leafIn[4] = {false, false, false, false};
int lotusPos = LOTUS_CLOSED;
unsigned long timer = 0;

// ---------- inputs ----------
byte readPCF() {                       // returns 8 bits, 0 = switch closed
  Wire.requestFrom(PCF_ADDR, (byte)1);
  if (Wire.available()) lastInputs = Wire.read();
  return lastInputs;
}
bool pcfClosed(byte bit) {
  byte a = readPCF(); delay(5); byte b = readPCF();
  return !(a & (1 << bit)) && !(b & (1 << bit));
}
bool pinClosed(byte pin) {
  if (digitalRead(pin) != LOW) return false;
  delay(10);
  return digitalRead(pin) == LOW;
}
int bandsSolved() { int n = 0; for (byte i = 0; i < 3; i++) if (pcfClosed(BIT_BAND[i])) n++; return n; }
int leavesIn()    { int n = 0; for (byte i = 0; i < 4; i++) if (pcfClosed(BIT_LEAF[i])) n++; return n; }

// ---------- outputs ----------
void show(const char* a, const char* b = "") {
  lcd.clear(); lcd.setCursor(0, 0); lcd.print(a); lcd.setCursor(0, 1); lcd.print(b);
}
void beep(int f, int ms) { tone(PIN_BUZZER, f, ms); delay(ms + 20); }
void allLeds(uint8_t r, uint8_t g, uint8_t b) { for (byte i = 0; i < 8; i++) leds.setPixelColor(i, r, g, b); leds.show(); }
void yugaLeds(byte k, bool on) {       // 2 LEDs per yuga: LEDs 2k and 2k+1
  for (byte j = 0; j < 2; j++)
    leds.setPixelColor(k * 2 + j, on ? YUGA_RGB[k][0] : 0, on ? YUGA_RGB[k][1] : 0, on ? YUGA_RGB[k][2] : 0);
  leds.show();
}
void moveSlow(Servo &s, int &pos, int target, int stepMs) {
  while (pos != target) { pos += (target > pos) ? 1 : -1; s.write(pos); delay(stepMs); }
}
void showCodePrompt() {
  char line[17] = "Code: ";
  for (byte i = 0; i < codeLen; i++) strcat(line, "*");
  show("Yuga Lotus Box", line);
}

// ---------- stage changes ----------
void goLocked() {
  lidServo.write(LID_LOCKED);
  allLeds(0, 0, 0);
  codeLen = 0;
  for (byte i = 0; i < 4; i++) leafIn[i] = false;
  state = LOCKED;
  showCodePrompt();
}
void goPuzzle() {
  wrongTries = 0;
  beep(880, 120); beep(1175, 200);
  lidServo.write(LID_OPEN);
  show("Unlocked!", "Open the box");
  delay(2000);
  timer = 0;
  state = PUZZLE;
}
void goLeaves() {
  show("Puzzle solved!", "Attach the leaves");
  beep(988, 120); beep(1319, 250);
  allLeds(0, 0, 0);
  state = LEAVES;
}
void goRing()   { show("All 4 leaves in!", "Turn the ring"); beep(1047, 120); beep(1397, 250); state = RING; }
void goButton() { show("Holes lined up!", "Push the button"); beep(1319, 120); beep(1568, 300); state = BUTTON; }
void goOpen() {
  show("The lotus opens", "...");
  for (byte k = 0; k < 4; k++) yugaLeds(k, true);
  moveSlow(lotusServo, lotusPos, LOTUS_OPEN, 15);
  int notes[] = {523, 659, 784, 1047, 784, 1047}, lens[] = {150, 150, 150, 300, 150, 450};
  for (byte i = 0; i < 6; i++) beep(notes[i], lens[i]);
  coinShown = 0; timer = 0;
  state = OPEN;
}

// ---------- test mode screen ----------
void showTest() {
  byte v = readPCF();
  char l1[17], l2[17];
  // 1 = closed (magnet present / pressed), 0 = open
  snprintf(l1, sizeof(l1), "Lf%d%d%d%d Bd%d%d%d R%d",
           !(v & 1), !(v >> 1 & 1), !(v >> 2 & 1), !(v >> 3 & 1),
           !(v >> 4 & 1), !(v >> 5 & 1), !(v >> 6 & 1), !(v >> 7 & 1));
  snprintf(l2, sizeof(l2), "Btn%d Lid%d *=out", digitalRead(PIN_BUTTON) == LOW, digitalRead(PIN_LID_CLOSED) == LOW);
  lcd.setCursor(0, 0); lcd.print(l1); lcd.print("   ");
  lcd.setCursor(0, 1); lcd.print(l2);
}

// ---------- setup ----------
void setup() {
  pinMode(PIN_BUTTON, INPUT_PULLUP);
  pinMode(PIN_LID_CLOSED, INPUT_PULLUP);
  pinMode(PIN_BUZZER, OUTPUT);
  Wire.begin();
  Wire.beginTransmission(PCF_ADDR); Wire.write(0xFF); Wire.endTransmission();   // all PCF pins as inputs
  lcd.init(); lcd.backlight();
  leds.begin(); leds.setBrightness(80); leds.show();
  lidServo.attach(PIN_LID_SERVO);
  lotusServo.attach(PIN_LOTUS_SERVO);
  lotusServo.write(LOTUS_CLOSED);
  show("Yuga Lotus Box", "Welcome!");
  delay(1500);
  goLocked();
}

// ---------- main loop ----------
void loop() {
  char key = keypad.getKey();

  switch (state) {

    case LOCKED:
      if (key >= '0' && key <= '9' && codeLen < 4) {
        entered[codeLen++] = key; entered[codeLen] = '\0';
        beep(1200, 40);
        showCodePrompt();
        if (codeLen == 4) {
          delay(300);
          if (strcmp(entered, SECRET_CODE) == 0) goPuzzle();
          else if (strcmp(entered, TEST_CODE) == 0) { state = TEST; lcd.clear(); }
          else {
            wrongTries++;
            beep(200, 500); show("Wrong code", "Try again"); delay(1200);
            codeLen = 0;
            if (wrongTries >= 3) { state = LOCKOUT; timer = millis(); } else showCodePrompt();
          }
        }
      } else if (key == '*') { codeLen = 0; showCodePrompt(); }
      break;

    case LOCKOUT: {
      unsigned long left = 10 - (millis() - timer) / 1000;
      char line[17]; snprintf(line, sizeof(line), "Wait %lu sec   ", left);
      lcd.setCursor(0, 0); lcd.print("Too many tries  ");
      lcd.setCursor(0, 1); lcd.print(line);
      if (millis() - timer >= 10000) { wrongTries = 0; state = LOCKED; showCodePrompt(); }
      delay(200);
      break;
    }

    case PUZZLE:                      // update the screen twice a second
      if (millis() - timer > 500) {
        timer = millis();
        char line[17];
        bool b[3];
        for (byte i = 0; i < 3; i++) b[i] = pcfClosed(BIT_BAND[i]);
        snprintf(line, sizeof(line), "Bands %c %c %c", b[0] ? 'Y' : '-', b[1] ? 'Y' : '-', b[2] ? 'Y' : '-');
        lcd.setCursor(0, 0); lcd.print("Solve the puzzle");
        lcd.setCursor(0, 1); lcd.print(line); lcd.print("    ");
        for (byte i = 0; i < 3; i++) leds.setPixelColor(i, b[i] ? 0 : 40, b[i] ? 120 : 0, 0);
        leds.show();
        if (b[0] && b[1] && b[2]) goLeaves();
      }
      break;

    case LEAVES:
      for (byte i = 0; i < 4; i++) {
        bool now = pcfClosed(BIT_LEAF[i]);
        if (now && !leafIn[i]) {
          leafIn[i] = true; yugaLeds(i, true);
          char line[17]; snprintf(line, sizeof(line), "%d of 4 leaves", leavesIn());
          show(YUGA_NAME[i], line);
          beep(1000 + i * 150, 150);
        } else if (!now && leafIn[i]) { leafIn[i] = false; yugaLeds(i, false); }
      }
      if (leavesIn() == 4) goRing();
      break;

    case RING:
      if (leavesIn() < 4) { show("A leaf came out", "Put it back"); state = LEAVES; }
      else if (pcfClosed(BIT_RING)) goButton();
      break;

    case BUTTON:
      if (!pcfClosed(BIT_RING)) { show("Ring moved", "Line holes up"); state = RING; }
      else if (pinClosed(PIN_BUTTON)) goOpen();
      break;

    case OPEN:
      if (millis() - timer > 2500) {
        timer = millis();
        show(YUGA_NAME[coinShown], YUGA_COIN[coinShown]);
        allLeds(0, 0, 0); yugaLeds(coinShown, true);
        coinShown = (coinShown + 1) % 4;
        if (coinShown == 0) { delay(2500); show("Collect coins!", "* to close"); for (byte k = 0; k < 4; k++) yugaLeds(k, true); timer = millis(); }
      }
      if (key == '*') {
        moveSlow(lotusServo, lotusPos, LOTUS_CLOSED, 12);
        show("Take out leaves", "then close lid");
        allLeds(0, 0, 0);
        state = RESETTING;
      }
      break;

    case RESETTING:                   // locks by itself once leaves are out and lid is shut
      if (leavesIn() == 0 && pinClosed(PIN_LID_CLOSED)) {
        delay(800);
        if (pinClosed(PIN_LID_CLOSED)) { beep(700, 100); goLocked(); }
      }
      break;

    case TEST:
      showTest();
      if (key == '1') lidServo.write(LID_OPEN);
      if (key == '2') moveSlow(lotusServo, lotusPos, LOTUS_OPEN, 8);
      if (key == '3') { lidServo.write(LID_LOCKED); moveSlow(lotusServo, lotusPos, LOTUS_CLOSED, 8); }
      if (key == '4') { for (byte k = 0; k < 4; k++) yugaLeds(k, true); delay(1500); allLeds(0, 0, 0); }
      if (key == '*') { lidServo.write(LID_LOCKED); moveSlow(lotusServo, lotusPos, LOTUS_CLOSED, 8); goLocked(); }
      delay(100);
      break;
  }
